## 📝 Overview

This repository contains **SQL practice queries and their outputs** for Week 1 of Databricks training.

The practice focuses on:

* Basic SQL queries
* Filtering data using conditions
* Sorting and grouping
* Aggregate functions
* Joins and subqueries

---

## 📅 Day 1: SQL Practice

### 🔹 Topics Covered

* SELECT statements
* WHERE conditions
* ORDER BY
* Aggregate functions (COUNT, AVG, MAX)
* GROUP BY & HAVING
* JOINS (INNER JOIN, LEFT JOIN)
* Subqueries

---

## 📂 Files Description

### 📌 queries.sql

Contains all SQL queries used for practice.

### 📌 results.md

Contains the output tables/results for each query executed using DB-Fiddle.

---

## 💻 Platform Used

* DB Fiddle (Online SQL Compiler)

## ▶️ How to Run

1. Open DB Fiddle
2. Copy the SQL from `queries.sql`
3. Execute queries one by one
4. Compare outputs with `results.md`
